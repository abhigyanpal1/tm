# Task Management API

## Overview
This Task Management API is built using Django and Django REST Framework. It enables users to:
- **Create Tasks:** Add new tasks with a name and description.
- **Assign Tasks:** Assign tasks to one or multiple users.
- **Retrieve Tasks:** Fetch all tasks assigned to a specific user.

The project is designed to be a lightweight yet functional solution for managing tasks and their assignments in a multi-user environment.
